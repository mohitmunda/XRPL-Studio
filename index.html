XRPL Token Studio

Create, manage, distribute and add liquidity to XRPL issued tokens.

Security: This app is intended to sign transactions in your browser. For real funds, prefer a hardware wallet or a trusted offline signing workflow. Never send your secret key to a server. Test everything on XRPL Testnet first. Creating an issued token does not create an independent blockchain or guarantee value/liquidity.

Create / Configure Token

On XRPL, a classic fungible token is identified by its currency code and issuer account. The issuer account already exists; this section configures it for token issuance.

Issue / Burn Tokens

For a traditional trust-line token, “burn” means sending issued tokens back to the issuer. The issuer cannot simply destroy another holder's balance.

Issuer Account Settings

Some token behavior is controlled by AccountSet flags. Choose carefully; some settings are difficult or impossible to reverse.

Add Liquidity / AMM

XRPL AMMs contain two assets. At most one can be XRP. Creating an AMM makes the creator the initial liquidity provider and issues LP tokens. For an existing pool, use AMM Deposit.
